# Arpan Basnet Personal Website

Hugo site for Arpan Basnet's electrical and electronics engineering portfolio, writing, projects, and research/publication records.

## Local Development

```bash
hugo server -D
```

Draft starter pages are included so the section layouts can be previewed before real content is published.

## Content Sections

- `content/posts/` - writing, lab notes, essays, field notes
- `content/projects/` - hardware, firmware, simulation, and prototype writeups
- `content/research/` - papers, posters, preprints, presentations, and publication records
- `content/experiences/` - education, internships, lab work, competitions, and technical roles

## New Content

```bash
hugo new posts/my-lab-note.md
hugo new projects/my-project.md
hugo new research/my-paper.md
hugo new experiences/my-role.md
```
